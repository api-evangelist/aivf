# AIVF

> AIVF develops AI-powered software for in vitro fertilization (IVF) clinics, embryology laboratories, and patients. Its EMA platform applies computer vision and machine learning to embryo evaluation, genetics, analytics, and clinic-patient communication to improve embryo selection and IVF success rates. AIVF holds a CE mark; in the US an AI component is an investigational device. AIVF publishes no public developer API — this profile captures the company's identity, security, and compliance surface for the API Evangelist network.
